# Фонарик Android

Одноэкранное приложение с одной кнопкой включения/выключения задней вспышки.

## Сборка APK через GitHub
1. Создайте новый публичный или приватный репозиторий GitHub.
2. Загрузите **содержимое папки Flashlight** в корень репозитория (включая скрытую папку `.github`).
3. Откройте вкладку **Actions**, выберите **Build Android APK** и нажмите **Run workflow** (или дождитесь сборки после загрузки).
4. После успешного выполнения откройте запуск и скачайте артефакт **flashlight-apk**.
5. Распакуйте архив артефакта: внутри будет **app-debug.apk**. Перенесите APK на Android и установите.

Примечание: GitHub может попросить включить Actions для нового репозитория. APK подписывается отладочным ключом и подходит для личного тестирования, но не для публикации в Google Play.
